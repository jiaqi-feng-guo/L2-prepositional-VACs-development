# Annotation scheme: constructional functions

*Duì*-constructions are verb-argument constructions in which *duì* (对) links a subject and an oblique argument to a verb or verb phrase, forming an integrated unit whose meaning arises from the interaction of its elements. Each correct instance is coded for one of six constructional functions, following the taxonomy established for native-speaker *duì* usage in the companion study (Guo, in press). The `Functions` column records the code.

| Code | Function | Definition |
|---|---|---|
| `DA` | Directed-Action | Introduces the target of a volitional action. |
| `SI` | Scoped-Intervention | Describes a bounded intervention upon a defined scope, where the marked participant is causally affected. |
| `MS` | Mental-State | Marks the stimulus of a feeling, or the item of knowledge held about it, where the state is internal and the marked participant is unchanged. |
| `ABT` | Aboutness | Marks the subject matter that a discourse verb engages, where something is said, written, or reported about it, and the matter itself is left unchanged. |
| `DISP` | Disposition | Describes a characteristic behavioural manner exhibited toward an entity in social interaction. |
| `EVAL` | Evaluation | Marks the affected party on whom the value or effect of something falls, the one who benefits or suffers by it. |

Worked examples for each function, with the diagnostics that distinguish neighbouring functions (for instance the boundary between Aboutness and topic marking, and between Evaluation and perspective), are given in the methodology section of the paper.
